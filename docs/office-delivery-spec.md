# Agenticcore office delivery — working specification

Status: proposal for scope and commercial validation. Neither route is connected to paid checkout or live delivery in the concept site.

## Two service routes

Managed office: select departments and workload; Agenticcore manages agreed delivery tools and capacity. Existing draft uses a 28-day service cycle with four weekly payments. Pricing, sustainable allowances and weekly change/cancellation rules require validation before payment integration. Paid advertising spend is separately approved. Third-party costs for managed work must be included in the priced scope, not added without agreement.

Company-owned office: commission a framework with a written scope, deployment/handover and custom identity preferences. Starting scopes are $1,500, $3,000, $5,000 and $10,000, subject to connection feasibility and requirements. These are not unlimited department implementations.

## Owned build milestones

1. Agreed scope and kickoff: 25%.
2. Prototype approval against agreed example tasks: 25%.
3. Integration testing and permission checks: 25%.
4. Acceptance, deployment and handover: 25%.

Each milestone needs written acceptance criteria. Changes require revised scope and cost before implementation. Final payment, acceptance, cancellation and IP terms belong in the service agreement, not inferred from the concept builder.

## Owned build handover

Define source rights, deployment configuration, documentation, administrator access, training, client-owned provider accounts, credentials transfer, data handling and third-party dependencies. Never transfer secrets through source control. Custom deliverable rights and third-party licenses are separate.

Ongoing costs can include API use, hosting, domains, messaging, storage and other third-party services. Estimate them before build. No mandatory Agenticcore support retainer; optional maintenance and scoped support are available. A written post-handover defect period covers agreed scope; provider migrations, new features and later support need explicit terms. No lifetime uptime or maintenance promise.

## Department work orders

Before a job is accepted, define client inputs, output, allowance consumption, revisions, delivery time, required tools, permissions and reviewer. Urgent documents and meeting briefs require an accepted deadline. Invoice emailing requires accurate client records, authorized sender access and explicit send/approval rules. Financial calculations must use reliable accounting/calculation software. Professional filings or sign-off require suitable scoped review.

## Next implementation gate

Validate managed unit economics and launch allowances. Finalize cancellation, weekly changes and defect support terms. Then implement one internal end-to-end workflow, with persistent task state, client isolation, approvals, verified outcomes and a factual nightly report. No payment integration before these definitions are agreed.
